Overview

This database supports the core functionality of an e-commerce application, including product management, shopper accounts, authentication, order processing, and payment tracking.

Current Milestone Tables

The current milestone includes the following tables:

- Product
- Shopper
- Access Token
- Order Record
- Order Item
- Payment

Future Milestone Tables

The following tables are planned for future milestones:

- Shipping Address
- Invoice

Keywords

- PK -> Primary Key
- FK -> Foreign Key


Product Table
=============

Purpose:
Stores information about products that shoppers can purchase.

Fields:
- product id (PK)
- product category
- product name
- product price
- in stock quantity
- created date
- modified date


Shopper Table
=============

Purpose:
Stores information about shoppers who use the application.

Fields:
- shopper id (PK)
- first name
- last name
- email address (unique)
- phone number
- password hash
- created date
- modified date


Access Token Table
==================

Purpose:
Stores authentication tokens associated with shoppers.

Fields:
- access token id (PK)
- shopper id (FK)
- token
- issued at
- expires at
- last used at
- is revoked


Order Record Table
==================

Purpose:
Stores information about who placed an order and the overall information associated with that order.

Fields:
- order id (PK)
- shopper id (FK)
- order date
- subtotal
- shipping fee
- total amount
- payment status
- order status
- created date
- modified date


Order Item Table
================

Purpose:
Stores the individual products belonging to an order.

Fields:
- order item id (PK)
- order id (FK)
- product id (FK)
- quantity
- unit price
- created date
- modified date


Payment Table
=============

Purpose:
Tracks payments associated with an order.

Fields:
- payment id (PK)
- shopper id (FK)
- order id (FK)
- total price
- payment status
- payment token
- last 4 digits
- card type
- created date


Future Milestones
=================

Shipping Address Table
----------------------

Status: Future milestone

Purpose:
Stores shipping addresses associated with a shopper.

This table is intentionally separate from the Shopper table so that a shopper can manage multiple addresses and reuse an address during the checkout process.

Fields:
- address id (PK)
- shopper id (FK)
- line one
- line two
- city
- state
- zip
- created date
- modified date

Invoice Table
-------------

Status: Future milestone

Purpose:
Records invoice information issued to shoppers.

Fields:
- invoice id (PK)
- shopper id (FK)
- invoice date
- due date
- invoice amount
- payment status
- exceeds credit limit status
- payment amount
- created date
- modified date
